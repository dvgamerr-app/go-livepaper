Prefer the command line?

Every wallpaper action works from a script. Omit -m to assign in Windows' monitor order, or target displays by number. 

# one image on the primary monitor
livepaper "C:\Wallpapers\mountain.jpg"

# one image per monitor
livepaper "left.jpg" "right.png"

# specific monitors by number
livepaper -m 2 -m 3 "portrait.jpg" "stats.png"
# live video wallpaper (ffmpeg)
livepaper "C:\Wallpapers\rain.mp4"

# same, rendered with mpv
livepaper --player mpv "rain.mp4"

# image on 1, video on 2
livepaper -m 1 -m 2 "left.jpg" "loop.mp4"

Two video renderers

Pick the backend with --player. Both ship in the installer — nothing to set up.

How it works

No magic — just the Win32 APIs, used carefully.

  1. Detect every monitor's position and resolution with EnumDisplayMonitors.
  2. Compose a canvas the size of the whole virtual desktop.
  3. Fit each image: load, apply EXIF rotation, fill-crop to the monitor and draw it in place.
  4. Apply the canvas as a Span wallpaper through SystemParametersInfoW.
  5. Play videos in a window embedded behind the desktop icon layer, looping forever.

Install in a minute

Download livepaper-setup-<version>.exe from Releases. It installs livepaper.exe plus bundled ffmpeg, ffprobe and mpv into %LOCALAPPDATA%\Programs\livepaper — and downloads nothing. 

# or build the CLI from source
go install github.com/dvgamerr/go-livepaper/cmd/livepaper@latest
# build the full app
git clone https://github.com/dvgamerr-app/livepaper-app.git
cd livepaper-app
bun install && bun run build
go build -tags production -o bin/livepaper.exe ./cmd/livepaper
