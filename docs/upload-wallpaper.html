1. Overview & Flow

การอัปโหลด wallpaper แบ่งเป็น 3 ขั้นตอนเสมอ:

POST /api/admin/wallpapers
→
PUT .../upload?type=thumbnail
→
PUT .../upload?type=original
→
✓ เสร็จ
ขั้นตอนEndpointหน้าที่
1 POST /api/admin/wallpapers สร้าง row ใน D1 — ได้ id และ R2 keys กลับมา
2 PUT /api/admin/wallpapers/:id/upload?type=thumbnail อัปโหลด thumbnail (webp แนะนำ 1920×1080)
3 PUT /api/admin/wallpapers/:id/upload?type=original อัปโหลดไฟล์ต้นฉบับ (png / mp4 ฯลฯ) — อัปเดต size_bytes + content_type อัตโนมัติ
⚠️ ต้องทำขั้นตอนตามลำดับ — POST ก่อนเสมอ เพราะ PUT ต้องการ id ที่มีอยู่ใน DB

2. Authentication

ทุก admin endpoint ต้องส่ง header:

Authorization: Bearer <ADMIN_TOKEN>

ADMIN_TOKEN ถูก set ไว้ใน Cloudflare Worker secrets:

# set production secret
bunx wrangler secret put ADMIN_TOKEN

# local dev — ใส่ใน .dev.vars
ADMIN_TOKEN=your_token_here

Base URL production: https://sso.dvgamerr.app

3. Step 1 — สร้าง metadata row

POST /api/admin/wallpapers admin

Request Body (JSON)

FieldTypeRequiredDescription
titlestring✅ชื่อ wallpaper
tier"free" | "premium" | "top"✅ระดับการเข้าถึง
contentTypestringควรระบุMIME type ของ original เช่น video/mp4, image/png
thumbnailContentTypestringควรระบุMIME type ของ thumbnail เช่น image/webp
widthnumber—ความกว้าง original (pixels)
heightnumber—ความสูง original (pixels)
isPublishedboolean—default true
idstring—ระบุ id เอง (รูปแบบ wp_<16hex>) หรือจะให้ระบบ generate ให้

Response

{
  "id": "wp_a1b2c3d4e5f60718",
  "thumbnailKey": "thumbnails/wp_a1b2c3d4e5f60718.webp",
  "originalKey": "originals/wp_a1b2c3d4e5f60718.mp4",
  "uploadHints": {
    "thumbnail": "PUT /api/admin/wallpapers/wp_a1b2.../upload?type=thumbnail",
    "original":  "PUT /api/admin/wallpapers/wp_a1b2.../upload?type=original"
  }
}

curl example

curl -X POST https://sso.dvgamerr.app/api/admin/wallpapers \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "My Wallpaper",
    "tier": "free",
    "contentType": "image/png",
    "thumbnailContentType": "image/webp",
    "width": 3840,
    "height": 2160
  }'

4. Step 2 & 3 — อัปโหลด thumbnail และ original

PUT /api/admin/wallpapers/:id/upload?type=thumbnail
PUT /api/admin/wallpapers/:id/upload?type=original

ส่ง body เป็น raw bytes ของไฟล์ — ไม่ใช่ multipart form

HeaderValueหมายเหตุ
Authorization Bearer <ADMIN_TOKEN> required
Content-Type MIME type ของไฟล์ ถูก store ใน R2 httpMetadata และ DB (type=original)

Response

{
  "id":   "wp_a1b2c3d4e5f60718",
  "key":  "originals/wp_a1b2c3d4e5f60718.mp4",
  "size": 53411840,
  "etag": "\"abc123...\""
}

curl — thumbnail

curl -X PUT "https://sso.dvgamerr.app/api/admin/wallpapers/wp_xxx/upload?type=thumbnail" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: image/webp" \
  --data-binary @thumb.webp

curl — original

curl -X PUT "https://sso.dvgamerr.app/api/admin/wallpapers/wp_xxx/upload?type=original" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: video/mp4" \
  --data-binary @video.mp4

5. สำหรับไฟล์ Video (Live Wallpaper)

วิดีโอต้องมี thumbnail ก่อนอัปโหลด — ใช้ ffmpeg extract frame:

# extract frame ที่ 5 วินาที → webp 1920x1080
ffmpeg -ss 5 -i "video.mp4" -vframes 1 -vf "scale=1920:1080" -q:v 80 thumb.webp
💡 แนะนำ thumbnail ขนาด 1920×1080 (16:9) format WebP เพื่อ performance ดีบนหน้า Browse Wallpaper

ตรวจสอบ dimensions ด้วย ffprobe

ffprobe -v quiet -print_format json -show_streams video.mp4

ลำดับ upload สำหรับ video

1
Extract thumbnail ด้วย ffmpeg

ได้ไฟล์ .webp ขนาด 1920×1080

2
POST สร้าง metadata

contentType: "video/mp4", thumbnailContentType: "image/webp"

3
PUT thumbnail → R2

?type=thumbnail + Content-Type: image/webp

4
PUT original video → R2

?type=original + Content-Type: video/mp4

ไฟล์ใหญ่ (50+ MB) อาจใช้เวลาสักครู่

6. ตัวอย่าง PowerShell Script

Upload image wallpaper (PNG)

$BASE  = "https://sso.dvgamerr.app"
$TOKEN = $env:ADMIN_TOKEN   # หรือใส่ตรงๆ
$HEADERS = @{ Authorization = "Bearer $TOKEN" }

# 1. สร้าง metadata
$meta = Invoke-RestMethod -Method POST "$BASE/api/admin/wallpapers" `
  -Headers $HEADERS `
  -ContentType "application/json" `
  -Body (ConvertTo-Json @{
    title                = "My Wallpaper"
    tier                 = "free"
    contentType          = "image/png"
    thumbnailContentType = "image/webp"
    width                = 3840
    height               = 2160
  })
$id = $meta.id
Write-Host "Created: $id"

# 2. Upload thumbnail
$thumbBytes = [IO.File]::ReadAllBytes("C:\path\to\thumb.webp")
Invoke-RestMethod -Method PUT "$BASE/api/admin/wallpapers/$id/upload?type=thumbnail" `
  -Headers $HEADERS `
  -ContentType "image/webp" `
  -Body $thumbBytes

# 3. Upload original
$origBytes = [IO.File]::ReadAllBytes("C:\path\to\image.png")
Invoke-RestMethod -Method PUT "$BASE/api/admin/wallpapers/$id/upload?type=original" `
  -Headers $HEADERS `
  -ContentType "image/png" `
  -Body $origBytes

Write-Host "Done! Wallpaper ID: $id"

Upload video (MP4 Live Wallpaper)

$BASE      = "https://sso.dvgamerr.app"
$TOKEN     = $env:ADMIN_TOKEN
$HEADERS   = @{ Authorization = "Bearer $TOKEN" }
$videoPath = "D:\path\to\video.mp4"
$tmpThumb  = "C:\Temp\thumb.webp"

# 0. Generate thumbnail
ffmpeg -y -ss 5 -i $videoPath -vframes 1 -vf "scale=1920:1080" -q:v 80 $tmpThumb

# 1. สร้าง metadata
$meta = Invoke-RestMethod -Method POST "$BASE/api/admin/wallpapers" `
  -Headers $HEADERS `
  -ContentType "application/json" `
  -Body (ConvertTo-Json @{
    title                = "Live Wallpaper Title"
    tier                 = "top"
    contentType          = "video/mp4"
    thumbnailContentType = "image/webp"
    width                = 3840
    height               = 2160
  })
$id = $meta.id

# 2. Upload thumbnail
$thumbBytes = [IO.File]::ReadAllBytes($tmpThumb)
Invoke-RestMethod -Method PUT "$BASE/api/admin/wallpapers/$id/upload?type=thumbnail" `
  -Headers $HEADERS -ContentType "image/webp" -Body $thumbBytes

# 3. Upload video (large file)
$vidBytes = [IO.File]::ReadAllBytes($videoPath)
Invoke-RestMethod -Method PUT "$BASE/api/admin/wallpapers/$id/upload?type=original" `
  -Headers $HEADERS -ContentType "video/mp4" -Body $vidBytes

Write-Host "Live wallpaper uploaded: $id"

7. อัปเดต metadata (PATCH)

PATCH /api/admin/wallpapers/:id admin

ทุก field เป็น optional — ส่งเฉพาะ field ที่ต้องการเปลี่ยน:

curl -X PATCH "https://sso.dvgamerr.app/api/admin/wallpapers/wp_xxx" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "tier": "premium", "isPublished": true }'

PowerShell

Invoke-RestMethod -Method PATCH "$BASE/api/admin/wallpapers/$id" `
  -Headers @{ Authorization = "Bearer $TOKEN" } `
  -ContentType "application/json" `
  -Body (ConvertTo-Json @{ tier = "premium"; isPublished = $true })

Delete (+ purge R2)

curl -X DELETE "https://sso.dvgamerr.app/api/admin/wallpapers/wp_xxx?purge=true" \
  -H "Authorization: Bearer $ADMIN_TOKEN"

8. Tier Reference

Tierการเข้าถึงใช้สำหรับ
free ทุกคน (ไม่ต้อง login) wallpaper ทั่วไป, static
premium ต้อง login + subscription premium wallpaper คุณภาพสูง, 4K
top ต้อง login + subscription top live wallpaper (video), exclusive

User ที่ไม่มีสิทธิ์จะได้รับ HTTP 402 Payment Required เมื่อพยายาม download

9. Content-Type Reference

ไฟล์contentTypeextensionหมายเหตุ
PNG imageimage/png.pngstatic wallpaper คุณภาพสูง
JPEG imageimage/jpeg.jpgไฟล์เล็กกว่า PNG
WebP imageimage/webp.webpแนะนำสำหรับ thumbnail
AVIF imageimage/avif.avifcompression ดีที่สุด
MP4 videovideo/mp4.mp4live wallpaper (H.264)
อื่นๆใดก็ได้.binfallback extension
✅ สรุป: สำหรับ video live wallpaper ให้ใช้ contentType: "video/mp4" และ thumbnailContentType: "image/webp" — thumbnail ต้อง generate ด้วย ffmpeg ก่อนเสมอ
